## Architecture

### server.py — proxy endpoints
| Endpoint | Description |
|---|---|
| `/ping` | Health check |
| `/proxy?url=...` | Proxies Forex Factory weekly JSON (whitelisted to nfs.faireconomy.media) |
| `/event-history?title=&country=USD\|EUR\|GBP&year=` | Full year history for one indicator |
| `/history?from=YYYY-MM-DD&to=YYYY-MM-DD` | Historical events from TradingView (max 60-day range) |

### Data sources
- **Primary**: TradingView Economic Calendar (`https://economic-calendar.tradingview.com/events`) — used for historical data and current week
- **Fallback / legacy**: Forex Factory JSON feed (`nfs.faireconomy.media`) — used via `/proxy` endpoint
- Country → currency mapping: US/EU/EMU/DE/FR/IT/ES/NL → EUR, GB → GBP, US → USD
- Impact mapping: TV integer 1=Low, 2=Medium, 3=High; keywords override unrated (0) events

### Key logic (server.py)
- `get_ff_week()` — fetches FF weekly JSON with retry logic
- `_fetch_tradingview()` — fetches TV calendar for a date range, normalises to FF schema
- `_fetch_event_history()` — fetches full year of one indicator's releases
- `week_bounds()` — calculates Mon–Fri date range for current or next week
- `_HIGH_KEYWORDS` regex — marks unrated TV events as High impact if they match known high-impact event names (NFP, CPI, FOMC, ECB, BoE, GDP, etc.)
- Chrome/146 User-Agent used to avoid bot detection
- curl used if available, falls back to urllib
