КРОК 1А Тренд / Імпульс — Top-Down аналіз
W1
Контекст — визначення A і B
  • План розширення weekly свічки (правило 3х свічок) — якщо свічка #2 закрилась тілом відносно свічки #1, то свічка #3 оновить min/max свічки #2. ⚠ NB! Якщо знімається велика полка ліквідності чи фрактал — правило може не спрацювати.
  • Точка A — остання external ліквідність що знімалась, або POI що тестувалась.
  • Точка B — протилежний свінг high/low або POI на W1.
⚠️
Перевірка валідності плану на H4
Після пошуку точок A/B на Weekly TF — перейди на H4 і перевір, чи план не інвалідовано.
План інвалідовано, коли на H4 ключовий свінг (який зародив останній рух) перебитий тілом.
D1
Bias + POI + FTA
  • D1 bias: [long] / [short] / [корекція]. Відмітити рівень Daily Open.
  • D1 POI: OB, FVG, RB, Int. Liquidity.
  • FTA — найближчий рівень що може зупинити рух.
  • Weekly Open / Monthly Open: якщо ціна вже далеко від WO/MO у напрямку угоди — потенціал руху обмежений.
  • Daily Open правило: рух вгору → шукати мінімум нижче DO; рух вниз → максимум вище DO.
  • День тижня: чи підходить для торгівлі? (см. розклад нижче).
H4
Уточнення зон або Добір позиції
  • Підтвердити точки A та B з D1.
  • H4 POI яка може розвернути ціну: OB / FVG.
  • Compression на H4 → сильний доп. фактор.
  • Для добору: наявність H4 shift.
H1
Модель входу пріоритет: OF inv > i-FVG > Shift 0.5R
  • Інвалідація OF → пробиття останнього протилежного BSL/SSL sweep.
  • Інверсія FVG (i-FVG) → сильний розворотний сигнал. Вхід від зони 0.5 i-FVG.
  • Market Shift → підтвердження розвороту від точки A. Вхід 0.5R.
  • H1 OB / FVG / i-FVG / RB → ліміт-ордер.
M15
Добір позиції (H4/M15)
  • H4 POI + QM M15.

1

FVG / i-FVG / OB що сформувалось при пробої → ТВХ.
4
Точка B — ціль за межами
POI або ліквідність на W1/D1. Не ціль всередині діапазону.

Крок 1 — Top-Down аналіз (W1 → M15)
W1
Макро-контекст + Ліквідність
  • Визначити глобальний напрямок: бичачий / ведмежий / боковик.
  • Великі BSL / SSL (тижневі максимуми / мінімуми).
  • Тижневий FVG та Order Block — зони реакції.
  • Де знаходиться ціна відносно попереднього тижневого діапазону?
D1
Bias + Daily POI
  • D1 bias: [long] / [short] / [корекція]. Відмітити рівень Daily Open.
  • D1 POI: OB, FVG, i-FVG, RB.
  • FTA — найближчий рівень що блокує рух.
  • Daily Open правило: рух вгору → шукати мінімум нижче DO; рух вниз → максимум вище DO.
  • День тижня: чи підходить для торгівлі? (см. розклад нижче).
H4
Підтвердження Order Flow
  • H4 POI: OB / FVG яка може розвернути ціну.
  • Compression на H4 → сильний додатковий фактор для продовження OF.
  • Volume Profile H4: натягнути VP → рівень POC = точка Part Fix (30–50%) + переведення SL у BE.
H1
Модель входу + Валідація
  • Market Shift на H1 → підтвердження розвороту від точки A.
  • i-FVG (інверсія FVG) → найсильніший розворотний сигнал. Вхід від зони 0.5 i-FVG.
  • H1 OB / FVG / RB → ліміт-ордер для входу.
M15
Тільки добір + Точне визначення входу
  • M15 — не первинний TF для входу. Використовувати тільки як добір до H1 позиції.
  • Asia session sweep / QM / shift → добір до H1 позиції.
Крок 2 — MMT Terminal (Volume & Order Flow)
MMT Screener Service — Workflow & Чекліст
🔥
Liquidity Heatmap
Відштовхуємось від рівнів ліквідності. Ставимо нотіфікації на рівні і в момент зняття — перевіряємо наступні умови для входу в позицію.
🫧
Large Trades on Spot
Великі агресивні угоди у зоні POI = підтвердження поглинання. Якщо великі угоди ростуть у напрямку угоди — сильний сигнал. Це і є зона POC.
📊
Orderbook Liquidity Depth
Coinglass: індикатор Orderbook Liquidity → Depth. Depth негативний і великий (напр. −2.5K+) = стіна продавців попереду ціни, рух вгору важкий. Depth близько до нуля або позитивний = шлях вільний. Перевіряй: чи немає великої ask-стіни між ціною і ціллю — це FTA що зупинить рух.
Δ
Cumulative Delta (CVD) Spot / Дисбаланс ордерів (Mobchart)
Дивергенція між ціною та CVD = попередження про розворот. Якщо CVD зростає — покупці агресивніші. Якщо падає — продавці домінують.
